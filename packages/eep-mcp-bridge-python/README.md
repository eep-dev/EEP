# eep-mcp-bridge (Python)

Python port of [`@eep-dev/mcp-bridge`](../../packages/@eep-dev/mcp-bridge) — MCP ↔ EEP bridge utilities and a reference HTTP bridge server.

## Install

```bash
pip install eep-mcp-bridge
```

## CLI

```bash
eep-mcp-bridge --help
```

## Development

```bash
pip install -e ".[dev]"
pytest
```
